კორბოული ვიკიპედია
საკმაოდ სუფთა ჰაერია რაც შენი ორგანიზმისთვის კარგია, ასევე არის ბევრი გასართობი როგორიცაა მდინარეზებანაობა და სასეირნო ადგილები, და არის ატრაქციონების პარკები.
